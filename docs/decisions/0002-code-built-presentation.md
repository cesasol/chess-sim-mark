# 0002 — Code-built presentation: Slate UI, procedural animation, scripted level

- Status: accepted (MVP)
- Date: 2026-10-20

## Context

The MVP needs a title/select screen, VN dialogue, choices, a chess HUD and live
character reactions. Blueprints, UMG widget assets, AnimBlueprints and
hand-edited levels are binary `.uasset`/`.umap` files. They are hard to review,
diff and regenerate, and the imported placeholder characters ship in T-pose
with no animations.

## Decision

- **UI** is a single Slate widget (`Source/ChessSimMark/UI/ChessSimHud.*`)
  built in C++. Every string comes from `Lines.csv` keys, so the UI follows the
  active culture. There are no UMG assets.
- **Character animation** uses a native `UProceduralAnimInstance` with a custom
  `FAnimInstanceProxy::Evaluate`. It outputs the ref pose plus procedural bone
  rotations: arms out of T-pose, breathing, lean, gaze and reaction impulses.
  Expressions use the VRoid `Fcl_*` face morph targets. Bones are found from
  candidate names (VRoid, MMD, Mixamo, UE mannequin), so swapping models only
  needs a `Model` column change in `Characters.csv`.
- **Level, materials and imports** are generated by editor-Python scripts
  (`Tools/import_assets.py`, `Tools/build_map.py`) run headless through `just`
  recipes. The `.umap` is a build artefact of those scripts.
- **Gameplay actors** (board, opponent, cameras) are C++ classes. The game mode
  finds them in the level, or spawns them with a default layout, so the game
  still runs in an empty map.

## Consequences

- Everything that matters is reviewable text and can be regenerated.
- Artists cannot tweak the UI in the UMG designer. Moving to UMG later stays
  possible because the game mode only talks to the HUD through `Show*`/`Set*`
  calls and callbacks.
- Procedural posing is limited compared with authored animation. When custom
  assets arrive, an AnimBlueprint can replace `UProceduralAnimInstance`
  without touching gameplay code: `AOpponentCharacter` only exposes
  `SetEmotion`, `React`, `SetTalking` and `SetLookTarget`.
